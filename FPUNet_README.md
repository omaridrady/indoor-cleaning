# FPUNet retraining (team)

1. Download from this repo: FPUNet_team_notebook.ipynb, ipa_training_maps.zip,
   fpunet_test_maps.zip and real_maps_for_colab.zip (click a file, then the download button).
2. Go to colab.research.google.com, sign in, then File > Upload notebook and
   choose FPUNet_team_notebook.ipynb.
3. Follow the instructions at the top of the notebook.

Optional: our first retrained model (best_fpunet_128_10.pth) is shared by Google Drive.
It is only used in Part 5 to compare against.
